# Laboratory Experiments

This folder contains the CSA4704 laboratory work. `CO1.ipynb` through
`CO5.ipynb` group the lab notebooks by course outcome, while
`Experiment_1_*` through `Experiment_30_*` contain the individual experiment
reports.

The reports cover matrix and probability foundations, optimization,
perceptrons and multilayer networks, CNNs, RNNs/LSTMs/GRUs, dimensionality
reduction, Bayesian networks, and generative models. Open the notebooks with
Jupyter or Google Colab; the DOCX and PDF files are supplied as completed
experiment records.
