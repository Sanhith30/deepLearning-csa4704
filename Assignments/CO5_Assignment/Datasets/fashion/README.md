# Fashion-MNIST Dataset

Place the official Fashion-MNIST files in this directory when reproducing the
assignment experiments:

```text
train-images-idx3-ubyte.gz
train-labels-idx1-ubyte.gz
t10k-images-idx3-ubyte.gz
t10k-labels-idx1-ubyte.gz
```

The parent CO5 README documents the source and explains the distinction between
official Fashion-MNIST results and the bundled demonstration data.
