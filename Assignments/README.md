# Assignments

This directory contains the five course-outcome assignment submissions for
CSA4704:

- [`CO1_Assignment/`](CO1_Assignment/) — AgriVision notebooks and reports.
- [`CO2_Assignment/`](CO2_Assignment/) — the CO2 notebook and report.
- [`CO3_Assignment/`](CO3_Assignment/) — recurrent-network experiments and
  reproducible result artifacts.
- [`CO4_Assignment/`](CO4_Assignment/) — PCA, factor analysis, ICA, sparse
  coding, Bayesian networks, and related experiments.
- [`CO5_Assignment/`](CO5_Assignment/) — energy-based and generative models,
  including RBMs, DBNs, VAEs, GANs, and evaluation experiments.

See the README in each assignment folder for its dependencies, run commands,
data requirements, and known limitations.
